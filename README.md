# 字幕PowerPoint作成ツール「subtitle_ppt」マニュアル

## 概要

このツールは、字幕原稿（subtitle.txt）からPowerPointファイル（subtitle.pptx）を自動生成します。  
字幕担当者は、テキストファイルを編集してプログラムを実行するだけでPowerPointを作成できます。  
このツールで生成された字幕ファイルはあくまで雛形です。
より読みやすい字幕への整形作業は手動で行うことを推奨します。

1行毎の文字数、フォント、文字の大きさ、行間、色、その他設定はmake_ppt.py内のソースを編集することで調整することが出来ます。  
全コピーしてAIに聞いてください。

---

## 事前準備

### 1. Pythonのインストール

このツールを使用するにはPythonが必要です。
Python公式サイトから最新版をインストールしてください。

インストール時は必ず「Add Python to PATH」にチェックを入れてください。

---

### 2. 必要ライブラリのインストール

初回のみ以下の作業を行います。
ターミナルを開き、次のコマンドを入力してください。

```bash
pip install python-pptx
```

「Successfully installed」と表示されたら完了です。


## フォルダ構成

subtitle_ppt.zipを解凍してデスクトップ上にsubtitle_pptフォルダを作成してください。


## 字幕ファイルの作成

subtitle.txtの中に字幕ファイルを入力してください

## 実行方法

### 1. subtitle_pptフォルダを開く

デスクトップの「subtitle_ppt」フォルダを開きます。

### 2. ターミナルを開く

フォルダ内の何もない場所を左クリックします。　　
その後、右クリック → 「ターミナルで開く」を選択してください。　　
ターミナル（黒い画面）が表示されます。

### 3. プログラムを実行

以下のコマンドを入力してEnterキーを押します。

```bash
python make_ppt.py
```


## PowerPointの生成

処理が完了すると、`dist` フォルダ内に `subtitle.pptx` が作成されます。


## よくあるトラブル

### pptファイルが生成できない
編集中のパワーポイントがあればすべて閉じてからプログラムを実行してください

### 「python が見つかりません」と表示される
Pythonがインストールされていないか、PATH設定がされていません。  
Pythonを再インストールし、「Add Python to PATH」にチェックを入れてください。

### 「No module named pptx」と表示される
必要ライブラリがインストールされていません。以下を実行してください。

```bash
pip install python-pptx
```

### PowerPointが作成されない
* subtitle.txt が存在するか確認する
* make_ppt.py が存在するか確認する
* ファイル名のスペルが正しいか確認する


## オリジナル版との差分
- テキストボックスの配置を上部に変更
- フォントを `BIZ UDPGothic` に変更
- 文字数の警告を、行ではなくスライド全体で評価するように
- 出力ファイル名に日付と時刻を含むように
- subtitle.txt で空行を3つ続けると、そこが黒スライド1枚になるように
- 保存先を `dist` フォルダに変更
